🔒 Política de Privacidade

Última atualização: 24/09/2026

Esta política explica quais dados o Jeffrey Bot coleta, como são usados e como você pode solicitar a remoção.

1. Dados coletados

O Bot coleta apenas os dados mínimos necessários para o funcionamento das funcionalidades:

  • IDs do Discord: ID do servidor, de canais e de usuários — necessários para aplicar comandos e configurações.
  • Configurações do servidor: preferências definidas por administradores (ex.: canais com bloqueio de convites ativo via !blockinvites/!allowinvites).
  • Nenhum conteúdo de mensagens: mensagens não são armazenadas. O Bot apenas analisa o conteúdo em tempo real para detectar convites, sem retê-lo.

2. Como os dados são usados

  • Para executar comandos solicitados pelos usuários (música, moderação, etc.).
  • Para aplicar a proteção anti-convites configurada pelo servidor.
  • Para garantir a estabilidade do Bot (trava de instância única).

3. Armazenamento e segurança

As configurações são armazenadas localmente em arquivos JSON na máquina que hospeda o Bot. Não há venda, aluguel ou compartilhamento de dados com terceiros.

4. Retenção e exclusão de dados

  • Dados de configuração podem ser removidos quando o servidor deixa de usar o Bot.
  • Você pode solicitar a exclusão dos dados relacionados ao seu servidor contactando o desenvolvedor.
  • Os dados não são compartilhados, utilizados para publicidade ou análise externa.

5. Menores de idade

O Bot não coleta dados pessoais de usuários. O uso do Discord está sujeito aos termos e à idade mínima exigida pelo Discord.

6. Alterações desta política

Esta política pode ser atualizada periodicamente. A versão mais recente estará sempre disponível nesta página.

7. Contato

Para dúvidas ou solicitações relacionadas a dados, entre em contato através do servidor oficial de suporte do Bot.
